# dusk

A screen dimmer for Windows and Linux. A bright desktop in a dark room stays harsh even at the lowest backlight setting, so the tool lays a translucent black shade over all monitors, over one monitor, or over a region drawn with the mouse, and the pointer passes through the shade to the windows underneath. The Region submenu of the tray menu lists each monitor and draws a region, and the moment the drag ends an editor opens on screen: a toolbar at the top right of the primary monitor, and a region that behaves like a window. It moves when dragged from its middle and resizes when dragged by an edge or a corner, and the pointer shows the matching move or resize cursor. A resize stops at a minimum size of eight pixels, and Escape during a drag puts the region back where the drag began. The toolbar's Delete button removes the region, and its Done button, Enter, or Escape closes the editor with the region as it was last left. The submenu's Move or resize the region item opens the editor again later. The dimming of all monitors on Windows goes through the system magnifier instead, so it also reaches the Start menu and the taskbar, which Windows draws above any shade while Start is open. The level runs from 10 to 90 percent in steps of ten, and the tool remembers the level and the target between runs. The Dim item of the tray menu or Ctrl+Alt+0 turns the dimming on and off, Ctrl+Alt+- makes it darker, and Ctrl+Alt+= makes it lighter. A choice of all monitors, one monitor, or a region only decides where the shade goes, so a region drawn while the dimming is off stays undimmed until Dim turns it on.
